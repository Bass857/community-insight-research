# 负责任使用与合规边界

“社区洞察调研”用于帮助用户整理有权访问的公开或已获授权社区内容。它的目标是提高研究过程的可回查性与边界透明度，不是规避平台限制的工具。

## 必须遵守的边界

1. **访问权限**：仅访问公开内容，或你已通过平台正常流程获授权访问的内容。
2. **登录与凭据**：登录应由使用者在平台正常界面完成。不要向 AI、Issue、PR、日志、截图或配置文件提供账号、密码、验证码、Cookie、Token、API Key、私钥或恢复代码。
3. **平台安全措施**：不得绕过验证码、人机验证、登录限制、频率限制、反爬机制、封禁或其他安全控制。出现访问受限时，应停止相应请求并改由用户决定是否等待、缩小范围或选择非等价的替代平台。
4. **个人信息与内容再分发**：不要收集、保存或公开不必要的个人信息。不要把完整社区内容、评论导出、抓取数据或用户报告提交到本仓库；引用时尽量保留必要的摘要和链接，并遵守内容来源的平台规则。
5. **研究结论边界**：社区内容不是随机抽样，可能包含软广、误导、过时信息和强烈的自选择偏差。不得将评论数、点赞数或个案直接视为市场份额、故障率、满意度或客观事实。
6. **关键事实核验**：涉及价格、版本、功能、政策、合规状态或安全能力的结论，应优先以官方来源核验；无法核验时明确写“未核实”。

## 使用者责任

使用者应自行确认符合：

- 目标平台的服务条款和社区规则；
- 所在地区适用的法律法规；
- 所在组织的数据安全、隐私和采购政策；
- 对第三方内容、商标和著作权的使用要求。

本文件是项目使用建议，不构成法律意见。
