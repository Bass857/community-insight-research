# 平台支持说明

本 Skill 的 `SKILL.md` 包含一个“历史兼容性参考”表，用来帮助使用者理解可能的搜索、正文和评论能力。

## 重要限制

- 该表不是兼容性保证、持续可用性承诺、平台授权声明或服务等级协议。
- 平台能力会受工具版本、浏览器、登录态、地区、账户权限、网络和平台策略影响。
- 每次实际调研前，应对用户确认的平台做一次轻量检查；登录失效、访问受限和功能缺失必须如实披露。
- 不得把访问失败或空结果解释成“没有相关讨论”。

## 外部工具

本 Skill 可选使用 [OpenCLI](https://github.com/jackwener/OpenCLI) 执行社区内容检索。OpenCLI 是独立项目；请使用其官方安装说明、许可证和安全边界。此仓库不打包其代码、浏览器扩展、配置或任何登录数据。

## 平台选择原则

AI 可以根据研究目的、目标人群、产品类型和地域推荐 1–3 个平台，但最终选择权属于使用者。替代平台只能补充某种视角，不能被表述为与原平台等价。
