# 社区洞察调研 / Community Insight Research

> 从社区真实声音到可回查的研究结论

一个协作式 NewMax Skill：帮助用户从公开社区讨论中了解产品、服务、品牌、模型或话题的真实体验、评价、风险、争议、用户需求与替代方案，并形成包含来源与限制声明的研究结论。

它不是“自动搜完全网后给结论”的黑箱工具。用户可以在关键节点决定本次调研的目的、重点、人群、平台、深挖方向和最终报告形式；AI 负责小范围试搜、证据整理、交叉验证与报告生成。

## 核心能力

- **协作式研究流程**：研究开始前确认目标；首轮试搜后由用户决定深挖、转向或收束。
- **阶段与最终报告分离**：过程发现必须标注“阶段性结论”；最终报告前必须确认报告形式。
- **多平台、可控范围**：AI 推荐平台，用户最终确认；默认不为凑样本而全量抓取。
- **证据可回查**：报告保留来源链接、证据要点、软广信号、官方事实核验和限制声明。
- **安全降级**：遇到登录失效或平台访问受限时停止相应请求，不绕过验证或风控，并将路径选择交还用户。
- **按需子 Agent**：只有在常规/深度调研且任务可独立拆分时，才按平台、目标人群或事实核验分工。

## 适用场景

- 产品、服务或品牌的真实评价与避坑研究
- AI 产品、开发者工具或 SaaS 的竞品洞察
- 用户需求、争议、替代方案与市场讨论研究
- 需要可点击来源和边界说明的社区证据库

## 不替代的研究方式

本 Skill 基于公开或获授权的社区内容，不能替代用户访谈、问卷、抽样统计、法律意见、专业尽调或实时数据服务。社区内容有自选择偏差、软广、时效差和平台规则限制；请结合你的实际决策场景核验关键事实。

## 关于 AI 协作

本仓库是一个 **人与 AI 协作完成** 的开源 Skill：

- 流程设计、规则边界、安全降级、报告模板和安装文档由 NewMax 上的 AI 助手与维护者协作起草。
- 提交历史、`SKILL.md` 章节结构和示例命令由维护者在 AI 辅助下迭代；任何改动都会通过 Pull Request 在公开仓库接受审阅。
- 维护者对每一处规则、命名与发布动作保留最终决策权；AI 助手不会自行合并、推送或更改仓库可见性。
- 本仓库不包含任何账号、Cookie、Token、平台登录态或用户抓取样本；所有执行均在用户本地 NewMax 环境中、由用户授权的浏览器中完成。
- 如果你发现规则漏洞、安全风险或边界问题，欢迎通过 [SECURITY.md](SECURITY.md) 中说明的方式私下反馈。

## 安装

### 在 NewMax 中安装

将本仓库作为 NewMax Skill 安装：

```text
community-insight-research
```

也可以在 NewMax 的 Skill 管理中选择本地文件夹或仓库地址安装。安装后内部调用名为：

```text
community-research
```

> 具体安装入口和可用安装方式以你使用的 NewMax 版本为准。[官方文档待补充]

### 手动使用（开发或审阅）

本仓库的核心文件为 `SKILL.md`。将其放入工作区的 `.claude/skills/community-research/`，或通过 NewMax Skill 安装器安装到全局 Skill 目录。

## 前置条件

- 使用 NewMax 运行该 Skill。
- 如需对社区内容进行实际检索，需要用户自行配置可用的数据访问能力。当前 Skill 可选使用 [OpenCLI](https://github.com/jackwener/OpenCLI) 和浏览器桥接。
- 任何需要登录的平台，应由使用者通过平台正常界面自行登录；不要在对话、配置文件、Issue 或仓库中提供密码、验证码、Cookie、Token 或其他凭据。
- 平台功能、地区可用性、登录要求和接口行为会变化。运行前应进行轻量连通性检查，而不是依赖本仓库的历史参考表。

## 快速示例

```text
请调研某款 AI 笔记工具的用户口碑。
重点看：为什么用户不续费，以及替代方案。
目标人群：个人知识工作者。
```

Skill 会先整理研究简报、推荐并请你确认平台；完成一轮小范围试搜后，再让你决定是否继续深挖负面、价格、竞品或特定人群。最终报告生成前，它会询问你需要决策版、产品洞察版、避坑版、市场舆情版还是证据库版。
